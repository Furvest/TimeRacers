# Практика 1.

Жанр: 2D Top-Down Racing (TimeRacers)
Ключевые параметры баланса:
  - Максимальная скорость (moveSpeed) — определяет темп игры и масштаб трассы.
    - Диапазон: 3–15.
    - Связь: Напрямую связана со Скоростью поворота (turnSpeed). Если скорость растет, а поворот остается прежним, машина перестает вписываться в повороты.
    - Влияние на игрока: Высокая скорость требует идеальной реакции и знания трассы, низкая — позволяет расслабиться.
  - Скорость поворота (turnSpeed) — определяет маневренность болида.
    - Диапазон: 60–180 градусов/сек.
    - Связь: Связана со Сцеплением (grip). Слишком высокий поворот при низком сцеплении вызовет неконтролируемый занос.
    - Влияние: Влияет на то, насколько агрессивно игрок может входить в повороты.
  - Сцепление (normalGrip и driftGrip) — определяет, насколько сильно машину сносит в поворотах (физика шин).
    - Диапазон: 1–20.
    - Связь: Связано с механикой дрифта. Низкое сцепление = скользкая трасса (как лед), высокое = аркадная езда "по рельсам".
    - Влияние: Низкое сцепление заставляет игрока постоянно корректировать курс, повышая сложность.

Обоснование выбора:
Эти параметры критичны, так как формируют "ощущение вождения" (Game Feel). Изменение скорости без изменения поворота ломает баланс трасс. Сцепление скрыто от игрока в цифрах, но отлично чувствуется руками (через геймпад или клавиатуру).

### Чек-лист выполнения практики

| Критерий | Реализация в проекте |
| :--- | :--- |
| Определены минимум 3 параметра | В CarStats.cs вынесены: скорость, ускорение, поворот, сцепление и др. |
| Указан типичный диапазон значений | В коде через [Range(1f, 20f)], а также в таблице GDD. |
| Описана связь параметров | См. таблицу GDD выше (влияние скорости на поворот и т.д.). |
| Описано влияние на игрока | См. таблицу GDD выше (агрессивность, скольжение, вес). |
| Обоснован выбор параметров | В GDD (эти параметры формируют "Game Feel"). |
| Создан SO с [CreateAssetMenu] | Скрипт CarStats.cs имеет атрибут [CreateAssetMenu(...)]. |
| Минимум 3 параметра вынесены из кода | Вынесено более 15 параметров (вся физика). Drive.cs только читает их. |
| Изменение в Inspector мгновенно влияет | Да, благодаря архитектуре ScriptableObject. Изменения применяются без перезапуска. |
| Скрипт ссылается через [SerializeField] | В Drive.cs есть поле [SerializeField] private CarStats stats;. |
| Код компилируется, ассеты создаются | Все скрипты собираются, в меню есть пункт Create -> TimeRacers -> Car Stats. |
| Создано более 2 вариантов конфигурации | Созданы и настроены ассеты Easy и Hard. |
| Параметры сгруппированы логически | Использованы атрибуты [Header("Скорость")], [Header("Сцепление")] в CarStats.cs. |
| Добавлены [Tooltip] и [Header] | Да, каждое поле в CarStats.cs снабжено подсказкой. |
| Параметры имеют ограничения | Использованы атрибуты [Range(...)] для защиты от некорректного ввода. |
| GDD содержит таблицу значений | Таблица параметров приведена выше. |
